# Retired Claims

The following claims must not be used in NEXUS publications or product material without new validated evidence:

- “The mini-brain is conscious.”
- “The mini-brain has learned memory.”
- “The mini-brain demonstrates criticality.”
- “The mini-brain is in a coordinated state.”
- “The mini-brain has a universal power law.”
- “v5 demonstrated memory recall.”
- “D4 provides a verified 3 dB gain.”
- “A coherence metric predicts all grid failures.”
- “The three-row reconstructed CSV is experimental data.”

Each retired claim requires a new controlled study before it can return to active status.
