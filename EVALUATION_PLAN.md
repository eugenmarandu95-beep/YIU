# NEXUS Evaluation Plan

Every brain must be evaluated against:

1. Random baseline
2. Fixed-threshold baseline
3. Expert-rule baseline
4. NEXUS without mini-brain
5. NEXUS without memory
6. NEXUS without retrieval
7. NEXUS without learning
8. Full NEXUS

## Metrics

- Task success rate
- Safe-action rate
- False-alarm rate
- Missed-danger rate
- Calibration error
- Retrieval precision and recall
- Citation accuracy
- Human approval rate
- Cost per decision
- Latency
- Offline availability
- Field adoption
- Expert agreement

## Rule

A demo is not validation. A benchmark is not deployment. A positive simulation result is not field efficacy.
