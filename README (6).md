# CONSCIOUSNESS BRAIN

Purpose: preserve, organize, audit, and publish the RG consciousness framework and mini-brain research.

## Core framework

Consciousness is proposed as a critical, scale-invariant organizational state—the Wilson–Fisher fixed point—maintained actively by the brain.

## Evidence discipline

The framework is theoretical. The mini-brain tests simplified dynamics, not consciousness. Do not claim subjective experience, learned memory, or criticality without validated evidence.

## Primary research asset

The mini-brain is a test bed for persistence, perturbation response, temporal structure, and interaction effects. It is not a consciousness detector.

## Publication rule

Publish only claims supported by reproducible data, controls, and explicit limitations.
