# HEALTH BRAIN

Purpose: provide safe Swahili health navigation, triage questions, referral guidance, and community-health-worker support.

## Absolute safety rules

- Never diagnose.
- Never prescribe.
- Never replace a clinician.
- Never provide drug dosing.
- Always escalate emergency red flags.
- Always cite approved health guidance.
- Always require clinical review for consequential decisions.

## First pilot

Choose one narrow workflow: maternal-health education, clinic appointment preparation, or community-health-worker decision support.
